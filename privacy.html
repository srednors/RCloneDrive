Privacy notice

RCloneDrive uses Google's authorisation process and Google Drive API to read, create, update and delete files as needed to synchronise folders selected by the user. Authorisation credentials are stored on the user's computer, separately from these public pages.

The configuration does not sell Google user data, use it for advertising, or send it to analytics services. Files, local recovery copies and Google Drive copies remain in locations controlled by the user. Retention depends on the user's sync, backup and deletion settings.

The user can revoke access in their Google Account's third-party connections settings. Revoking access stops future access; it does not itself delete existing file copies or backups.

These information pages contain no sign-in, forms, analytics or embedded third-party resources, and their code sets no cookies. GitHub Pages hosts them and logs visitor IP addresses for security, as described in the GitHub Privacy Statement. Google's processing of account and Drive information is covered by the Google Privacy Policy.

For questions, use the support address displayed on the Google authorisation screen.
